## Why Google Flagged the Previous Version
Google's automated review system flagged **Yellow Argon (Keyword Spam)** because the previous listing description contained lists of portal names (`UMS, MyClass, LPULive, OAS, NeoBrowser`) and technical library names (`Tesseract.js`). 

Google's spam guidelines prohibit:
1. Listing brand/portal names in list or keyword format (perceived as search-rank manipulation).
2. Mentioning internal JavaScript libraries (like `Tesseract.js`) that are irrelevant to end users searching the store.

The updated text above describes the **functionality and user benefits in natural sentences** without keyword stuffing, making it 100% compliant with Chrome Web Store policies.
